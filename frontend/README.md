# PlantAI 🌿

AI-powered medicinal plant identification platform.

## Features

- Plant image upload
- AI plant identification
- Scientific name detection
- Confidence score analysis
- Medicinal plant information
- Modern responsive interface

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python
